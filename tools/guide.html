Tools 説明書

セッション準備・進行向けの便利ツールの使い方です。サイト全体の案内は 使い方ガイド を参照してください。

Tools はホーム「その他」の Tools から開けます。PDF・ログ・ZIP などはブラウザ内だけで処理します。サーバーへアップロードしません。

1. 共通の注意

  • NPCコマ・オリジナル表・ログ抽出・部屋zipは、ログインしなくても使えます。
  • セッションボードのキャラ参照と「卓から並べる」は、Discord ログインと名簿連携があると確実です。
  • 入力内容は原則としてこの端末の画面上だけです。ページを閉じたりリロードしたりすると消えます（セッションボードは JSON で書き出せます）。

2. NPCコマ作成

ココフォリアに貼り付けできるキャラクター JSON を作ります。

  1. 名前を入力します。
  2. ステータス（HP など）を行追加して、現在値・最大値を入れます。
  3. パラメータ（STR など）を入力します。「ダイス」や「一括ダイス」で 6 版想定の出目を振れます（STR・CON・POW・DEX・APP は 3D6、SIZ・INT は 2D6+6、EDU は 3D6+3）。
  4. イニシアチブを必要なら手入力します。ダメージボーナスは STR+SIZ から自動表示されます。
  5. 表示設定（ステータス非公開、発言時非表示、盤面一覧に出さない）を選びます。
  6. コマンドはプリセットから足すか、自分で追加します。
  7. 「ココフォリア JSON をコピー」を押し、ココフォリアへ貼り付けます。

3. オリジナル表

ココフォリアの /roll-table 形式テキストを作ります。

  1. 表タイトルと項目数（1〜100）を決めます。
  2. 各項目の文言を入力します。右側に作成結果がリアルタイムで出ます。
  3. 「テキストをコピー」を押し、ココフォリアのチャットへ貼り付けます。
出力は /roll-table、タイトル、1D項目数、1:内容 という行です。空の項目も番号だけ残ります。

4. ココフォリアログ抽出ツール

ココフォリアから書き出したログ HTML を読み、判定結果行を絞り込みます。

  1. 「ログファイル」から HTML を選びます。処理は端末内です。
  2. 出てきたキャラクター・タブから、見たいものだけ残します。
  3. 判定結果フィルタ（成功／スペシャル／クリティカル／失敗／ファンブル）でさらに絞ります。未選択なら全件です。
  4. 最終 SAN は、ログ時点の各キャラの値を一覧表示します。
  5. 「表示中のログをコピー」で、今見えている行をテキストとして取れます。
目標値なしの 1d100 は、出目 1〜5 をクリティカル、96〜100 をファンブルと判定します。

5. ココフォリア部屋zip作成

試作品です。書き出した ZIP の内容は自分で確認し、自己責任で使ってください。

空ルームのテンプレートへ、シーン・ノート・キャラを流し込んで部屋 ZIP を書き出します。ファイルはブラウザ内だけで処理されます。

  1. テンプレート: 内蔵テンプレのまま使うか、手元の部屋 ZIP を選びます。
  2. シーン: 前景画像を選び、差し替えまたは追記します。背景は既定で前景と同じです。一覧の選択欄で「前景と同じ」「背景なし」、他シーンの画像、または背景ファイルを指定できます。サイズや収め方は一覧から調整できます。
  3. シナリオテキスト: ノートを 1 件ずつ、または --- 区切りで一括追加します。
  4. キャラクター: 名前から追加し、ステータス・パラメータ・アイコン・チャットパレットなどを編集します。
  5. 「ZIPを書き出す」でダウンロードします。
差し替えは既存の該当データを置き換え、追記は足します。クリアするとその欄の追加分を捨てます。

6. セッションボード

シナリオ PDF・複数キャラの能力値／技能・メモを、自由なパネルとして 1 画面に並べます。セッション中の参照用です。

パネルの操作

  • タイトルバーをドラッグして移動、四隅をドラッグしてリサイズします。
  • クリックしたパネルが前面に来ます。× で閉じます。
  • PDFを追加: 手元の PDF をパネルで開きます。
  • キャラを追加: サイトに登録したキャラから選びます。表示するのは能力値と技能だけです（画像・プロフィール・登録メモは出しません）。
  • メモを追加: その場のメモ用テキストです。
  • 卓から並べる: 進行中・計画中の卓の参加キャラをまとめて追加します。終了済みの卓は出ません。

画面を広げる

「画面を広げる」で上部ナビとツールバーを隠します。右上の「メニューを表示」または Esc で戻ります。

JSON の書き出し／読み込み

  • リロードやタブを閉じると作業内容は消えます。続きから使うときは「JSONを書き出す」してください。
  • JSON に入るのはパネル位置・メモ本文・キャラ ID・PDF のファイル名だけです。PDF 本体・ファイルサイズ・更新日時は入りません。
  • 読み込み後、PDF パネルは同じファイルを選び直します。パネルの「このPDFを選び直す」か、ツールバーの「PDFを割り当て」でファイル名が一致するものを割り当てます。
キャラ一覧が出ないときは、Discord ログインとプレイヤー連携を確認してください。
