便利ツール

セッション準備・進行向けの道具です。PDF やテキストは端末内で処理します。セッションボードのキャラ参照はログイン推奨です。

NPCコマ作成

名前・ステータス・パラメータ・コマンドからココフォリア用 JSON を作ります。

オリジナル表

表タイトルと項目から /roll-table 形式のテキストを作成します。

ココフォリアログ抽出ツール

ログ HTML を読み込み、判定結果行を表示・絞り込みます。最終 SAN も一覧表示します。

ココフォリア部屋zip作成

シーン・ノート・キャラを流し込んだココフォリア部屋 ZIP を作成します（試作）。

セッションボード
