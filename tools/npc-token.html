NPCコマ作成

ココフォリアに貼り付けできるキャラクター JSON を作ります。パラメータ変更で HP / MP / SAN・イニシアチブを自動更新しますが、手編集もできます。

パラメータ

ダイス: EDU=3D6+3 ／ SIZ・INT=2D6+6 ／ その他=3D6

ステータス

HP = ceil((CON+SIZ)/2)　／　MP = POW　／　SAN = POW×5（自動更新・編集可）

表示項目

ダメージボーナス
―

ダメージボーナスは STR+SIZ の表から算出（表示のみ）。イニシアチブは JSON の initiative に入ります。

表示設定

コマンド

各行の「秘密」をオンにすると、そのコマンド先頭に s を付けて書き出します。
